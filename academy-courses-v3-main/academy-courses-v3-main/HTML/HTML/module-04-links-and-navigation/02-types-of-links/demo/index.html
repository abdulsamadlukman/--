Course Progress

I'm building this portfolio module by module, as I work through Publica Academy's HTML & CSS Basics course. Here's what I've completed so far.

  1. Intro to Web Dev — setting up my tools, and building my very first HTML file
  2. HTML Document Structure — the skeleton every page is built from, and how to keep it clean
  3. Text & Content Elements — headings, formatting text properly, and organizing content into lists
  4. Links & Navigation — this module, right now, learning to connect pages together

Every module has felt like a small levelling-up moment. Module 1 was mostly about learning the tools — VS Code, Live Server, DevTools — and understanding, at a high level, how a browser turns a request into the page you see. Module 2 slowed things down and made me actually understand the skeleton I'd been copying without thinking about: the doctype, the html tag, the head, the body, and why nesting has to close in the right order. Module 3 is where the page started to look like something a real visitor might actually want to read — headings that make sense as an outline, bold and italic used for the right reasons instead of just because they look nice, and lists that organize information instead of just listing it. And now, Links & Navigation — the module where all these separate pages I've been building finally start to connect to each other, the way a real website does.

I'm not rushing any of this. Understanding why something works has mattered more to me than getting to the end of a checklist, and I think that's shown up in how much more confident I feel writing HTML from scratch now compared to when I started.
