A Logo: Why PNG

This logo has a transparent background. You can't fully see it here yet, since this page has no colour behind it — once CSS backgrounds are introduced, transparent PNGs like this one will sit cleanly on top of any colour or pattern. JPEG cannot do this at all; it always fills in a solid background.

An Icon: Why SVG

The same icon, twice — once tiny, once huge. Both stay perfectly sharp, because SVG isn't a grid of pixels, it's a set of drawing instructions the browser draws fresh at any size.
